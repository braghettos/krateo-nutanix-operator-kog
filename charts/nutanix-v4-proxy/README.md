# nutanix-v4-proxy (Helm chart)

Deploys the [Nutanix v4 translating proxy](../../quickstart/middleware/nutanix_v4_proxy.py)
that lets the Krateo `rest-dynamic-controller` (generated by oasgen-provider / KOG) drive the
Nutanix Prism Central **v4** API. The proxy performs the translations a schema-agnostic
controller can't:

1. OData `$filter` quoting — `?name=X` → `name eq 'X'`
2. `$objectType` discriminator injection (derived from the request path)
3. `NTNX-Request-Id` UUID on POST/PUT/DELETE
4. async **task** resolution — `202` + TaskReference → poll → return the real resource
5. ETag / `If-Match` on PUT/DELETE, **and** parent `If-Match` on child creates (5b)
   plus optional default `X-Cluster-Id` for cluster-scoped endpoints

## Install

From the published OCI registry (image + chart are pushed by CI on each `v*.*.*` tag —
see `.github/workflows/release.yml`):

```bash
helm install nutanix-mw oci://ghcr.io/braghettos/charts/nutanix-v4-proxy --version 0.2.0 \
  -n nutanix-system --create-namespace \
  --set config.pcBase=https://<PC-HOST>:9440/api \
  --set config.xClusterId=<registered-PE-cluster-extId>      # optional
```

Or from a local checkout:

```bash
helm install nutanix-mw charts/nutanix-v4-proxy -n nutanix-system --create-namespace \
  --set config.pcBase=https://<PC-HOST>:9440/api \
  --set config.xClusterId=<registered-PE-cluster-extId>      # optional
```

`config.pcBase` is **required** (must end in `/api`) — the chart refuses to render without it.

Point your RestDefinition OAS slices' `servers[0].url` at the in-cluster service printed by
`helm install` (e.g. `http://nutanix-mw.nutanix-system.svc.cluster.local:8080`). Use
`fullnameOverride: nutanix-mw` to keep that exact name.

## Key values

| key | default | purpose |
|---|---|---|
| `image.repository` / `image.tag` | `ghcr.io/braghettos/nutanix-v4-proxy` / `0.2.0` | image; set `image.digest` to pin |
| `config.pcBase` | `""` (**required**) | Prism Central API base, ending in `/api` |
| `config.tlsVerify` | `false` | verify the PC TLS cert (PC often uses a private CA) |
| `config.xClusterId` | `""` | default `X-Cluster-Id` for cluster-scoped endpoints |
| `config.taskTimeoutSeconds` | `180` | async task poll budget |
| `config.objectTypeOverrides` | `{}` | `{"<path-prefix>": "<$objectType>"}` for irregular paths |
| `config.logLevel` | `INFO` | `INFO` / `DEBUG` |

Runs hardened by default: non-root (`65532`), read-only rootfs, all caps dropped,
`RuntimeDefault` seccomp. Liveness/readiness on `/healthz`.

## Build the image

```bash
docker build --build-arg VERSION=0.2.0 \
  -t ghcr.io/braghettos/nutanix-v4-proxy:0.2.0 quickstart/middleware
```

The base image is pinned by digest for reproducible builds. For a registry-free trial, the
[`quickstart/middleware/deploy.yaml`](../../quickstart/middleware/deploy.yaml) manifest mounts
the script from a ConfigMap onto `python:3.11-slim` instead.
